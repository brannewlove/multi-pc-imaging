맞춤 파티션 권장양식 및 자동매칭 규칙

대상 PC가 부팅되면 HDD 용량, 개수, 번호 및 모델명을 판별하여 일치하는 양식을 자동 선택합니다. 조건에 일치하고 '자동 승인'이 켜져 있으면 작업자의 클릭 없이 즉시 더빙이 진행됩니다.

📀

마스터 이미지 폴더 및 기종별 선택 규칙

📁 1. 마스터 이미지 저장 폴더 설정

0개 WIM 감지됨

배포할 OS WIM/ESD 이미지들이 보관된 마스터 PC의 로컬 폴더 또는 네트워크 공유 경로를 지정합니다.

폴더 스캔을 실행하여 WIM 이미지 목록을 확인하세요.

🎯 2. 기종별 마스터 이미지 선택 규칙 (Priority Matching Rules)

타깃 PC가 부팅되면 위에서부터 우선순위대로 제조사, 모델명, SSD 용량을 대조하여 일치하는 WIM 이미지를 자동 지정합니다.

🧪 3. 규칙 매칭 실시간 테스트 (시뮬레이터)

사양을 입력하고 테스트를 실행하면 어떤 WIM 이미지가 선택되는지 즉시 확인할 수 있습니다.
